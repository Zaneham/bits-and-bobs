stress_cae.ml, 4 domains. amd64 native, the rest cross-compiled and run
under qemu-user. qemu-user serialises, so these show the encodings
assemble and the logic holds. They do not exercise the fences.

  PASS: cas hit stored
  PASS: cas miss returns false
  PASS: cas miss left value alone
  PASS: cas to same value

  PASS: exchange stored
  PASS: bool cas hit
  PASS: bool cas miss
  PASS: bool value
  PASS: negative cas
  PASS: negative stored
  PASS: max_int cas
  PASS: max_int stored
